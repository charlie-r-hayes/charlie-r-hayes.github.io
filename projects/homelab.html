CUSTOM HOMELAB

PROXMOX • LINUX • NETWORKING

PROJECT // OVERVIEW

ABOUT THE PROJECT

I built this homelab as a platform for learning virtualization, networking and mainly self-hosting.

Rather than relying on cloud services and paying loads for subscriptions, I can work on a project that I enjoy, store my data more privately and help my family and friends out too.

◫
VIRTUALIZATION

Proxmox VE running multiple virtual machines and containers.

⑂
NETWORKING

OPNsense firewall, VLANs, routing, DNS, and remote access.

⚙
SELF-HOSTED SERVICES

Game servers, Pi-hole, monitoring, storage, and development tools.


Right now my homelab is in a husk under my desk. Soon I will organize it into a 10 inch rack to for efficiency and visual appeal.

PROJECT GOALS

The main goal was to build an area where I could self-host services like file and photo storage, video game server hosting, media hosting and more for myself and family and friends.

  • Learn virtualization and server administration
  • Build and configure a custom network
  • Deploy reliable self-hosted services
  • Develop stronger troubleshooting skills

DESIGN PROCESS

The design process involves getting the hardware you are going to use and making sure that whenever you put everything together it turns on. Then you install your software and when something inevitably breaks you work to fix it. After you finally get it working you can give your parents and friends access.

CHALLENGES

The challenges I face when building my homelab are neverending. The cool thing about homelabs is how customizable they are, no one persons is the same as the other. Hardware tends to almost always be different as some of the main ways to get computing power is secondhanded. But with everything being different, it means you have a big chance of running into problems that are specific to you. I cannot being to tell you how many hours of troubleshooting I've gone through, but so far I've yet to run into a problem that I have not been able to fix, and in the end all that troubleshooting has been worth it.

RESULTS

When working with homelabs there is really no "end result". Self-hosting is something that is continually evolving and changing, it is just something that I try to make as good as I possibly can.
