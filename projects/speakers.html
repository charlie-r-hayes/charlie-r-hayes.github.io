CUSTOM HOMELAB

PROXMOX • LINUX • NETWORKING

PROJECT // OVERVIEW

ABOUT THE PROJECT

I built this homelab as a platform for learning virtualization, networking, Linux administration, storage, self-hosting, and infrastructure design.

Rather than relying entirely on cloud services, the system gives me hands-on experience deploying, troubleshooting, maintaining, and improving real infrastructure.

◫
VIRTUALIZATION

Proxmox VE running multiple virtual machines and containers.

⑂
NETWORKING

OPNsense firewall, VLANs, routing, DNS, and remote access.

⚙
SELF-HOSTED SERVICES

Game servers, Pi-hole, monitoring, storage, and development tools.

KEY TECHNOLOGIES

  • Proxmox VE
  • Linux
  • OPNsense
  • Pi-hole
  • Docker
  • Tailscale
  • LXC Containers

HARDWARE

  • 64 GB DDR5
  • NVMe Storage
  • Custom Rack
  • Managed Networking

PROJECT GOALS

The main goal was to build a flexible environment where I could experiment with technologies that would be difficult to learn exclusively through coursework.

  • Learn virtualization and server administration.
  • Build and configure a custom network.
  • Deploy reliable self-hosted services.
  • Develop stronger troubleshooting skills.
